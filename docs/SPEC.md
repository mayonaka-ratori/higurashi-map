## 画面構成

1画面完結。画面遷移はしない。画面幅1024px以上でPC、それ未満でスマホの組み方になる。

### ヘッダー

- タイトル「ひぐらしのなくところに」
- PCはキャッチコピー「今日、カナカナが聞こえる場所。」、スマホは現在時刻

### 時間帯レール（全幅）

1日を横一本の帯にしたもの。上部に置く。

- 朝と夕の「聞きどき」（夜明け・日の入りの前後30分）を色の帯で示す
- 夜明け・日の入りの時刻、0/6/12/18/24時の目盛り（PCのみ）、現在時刻のマーカー
- **今日届いた報告を時刻の位置に点で打つ**（聞こえた=緑 / 静かだった=灰）。
  上下に交互に振って同時刻の重なりを避ける
- 状態文「いま聞きどき・朝／夕」「朝（夕）の聞きどきはこれから」「今日の聞きどきは過ぎた」と残り時間
- 補足「鳴くのは夜明けと日の入りの前後30分が中心です」／
  日中は「曇りの日や暗い林なら、日中でも鳴きます」

実装: [src/components/DayRail.tsx](../src/components/DayRail.tsx)、
計算: [src/lib/sun.ts](../src/lib/sun.ts) の `listeningWindows`

### 地図

- MapLibre GL + 国土地理院タイル
- スポットをピン（丸）で色分け表示:
  - 🟢 今日「聞こえた」報告あり
  - 🟡 3日以内
  - ⚪ 今シーズン（6/1以降）
  - ⚫ 今シーズンの記録なし
- ピンはズームに応じて大きさが変わる。タップ判定は周囲10pxまで拡大
- 今日のピンだけ波紋が出る（`prefers-reduced-motion: reduce` で止まる）
- ズーム9.8以上で今日のピンに地点名が出る。重なる分は自動で間引かれ、
  PCは右パネルの下に文字を出さない
- 地点を選ぶと地図が寄る。PCは右パネル幅の半分（x −202px）、スマホは下へ（y −110px）ずらす
- 地点名検索（登録スポットの名前・市区町村・都県名。全角半角・大小文字の違いは吸収）
- 凡例はPCのみ左下

### 答えのブロック（PCは右パネル404px / スマホは下端の固定カード196px）

その日の記録から**答えを一つ**出す。

- 今日「聞こえた」記録があり、かつ期待度3以上の場所があれば
  「今夜はここ」（朝の聞きどき中は「今朝はここ」）＋地点名＋♪＋根拠＋コメント
- 条件を満たさない日は**別の画面**に切り替える:
  - 今日の報告が1件でもある → 「確かなことは、まだ言えません」
  - 1件も無い → 「今日はまだ誰も聞いていません」
  - ボタンは「近い順にならべる」に変わる
- その下に候補を最大5件（PC）／6件（スマホ）。
  **見出しは母集団と連動**する（実績のある場所が無い日に「実績のある場所」と名乗らない）
- 並び替え: おすすめ順（期待度から距離を割り引いたもの）／近い順

### スポット詳細（PCは右パネルを差し替え / スマホは下から出るシート）

- 鮮度ラベル・地点名・所在地・距離
- 期待度♪と言い換え（よく鳴いている／鳴いている／たぶん鳴く／望みはある／わずか／記録なし）
- 根拠の一行・今日◯件確認・昨日◯件・今シーズン計◯件
- 外部記録があれば出典リンク付きで表示
- 今日の報告一覧（最新8件）・X共有リンク
- **投稿の2ボタンは下端に固定**。スクロールしても消えない

### 投稿フロー

その場で聞いた分:

1. 常駐の「🌲 いま聞こえた」（PCは答えカードの右、スマホは地図右下）を押す
2. 現在地から近い3件が出る。押した時点で記録される（地点を先に選ばなくてよい）
3. 「この中にない — 地図から選ぶ」で地図選択に落ちる

スポット詳細からも投稿できる（「🌲 カナカナ聞こえた！」「🌙 今日は静かだった」）。
あとから記録する分は「さっき聞いた分を記録」→ 時刻チップ（さっき / 1時間前 / 今朝 / 昨日の夕方）
を選んでから場所を押す。朝と夕はその日の実際の夜明け・日の入りの時刻で記録する。

送信すると「送信中…」→ 完了カード
「カナカナ情報を受け取りました。今日ヒグラシを探している誰かの助けになります。」。
「聞こえた」のときは「この場所のピンが今 🟢 になりました。」と「𝕏 でシェアする」を出す。
失敗したときは「送信できませんでした」と「もう一度送る」を出す。

制約: 同じスポットへの連続投稿は2分あける（端末内チェック）。

### X共有

- 共有URLは `/?place=地点ID` 形式。開いた人はその地点が選択された状態で着地する
- 文言（聞こえた直後）: 「◯◯でヒグラシの声を確認しました🌲 #ひぐらしのなくところに」

## 期待度の計算（ルールベース、AI不使用）

| 条件 | 点 |
|---|---|
| 30分以内に「聞こえた」 | +30 |
| 3時間以内に「聞こえた」 | +10 |
| 24時間以内に「聞こえた」 | +5 |
| 3時間以内に「聞こえた」2件以上（複数人確認） | +20 |
| 直近の「聞こえた」がGPS高精度（50m以内、3時間以内） | +10 |
| 3時間以内の「静かだった」1件につき | -5（最大-15） |
| 外部サイトの記録が3日以内（日付が特定できるもの） | +10 |
| 外部サイトの記録が今シーズン内（月のみ判明を含む） | +5 |

♪変換: 55点以上=5 / 35以上=4 / 20以上=3 / 10以上=2 / 1以上=1 / 0=0
実装: [src/lib/score.ts](../src/lib/score.ts)

期待度は **♪** で表す（点いた分だけ出し、0件のときは何も出さない）。
2026-08-09の再設計より前は★だったが、★はレビュー点数に見える——
評価しているのは場所そのものではなく「その日その時間に鳴いていそうか」なので、単位を変えた。
おすすめ順では、期待度から距離1kmにつき0.5点（最大30点）を引く（`rankScore`）。
「♪5だが80km先」が1位に来ないようにするためで、♪の値そのものは変えない。

外部記録（2026-08-08追加）は運営が公式サイト・ブログ・登山記録などから
調べたもので、places.json の `externalRecord` に置く（フィールド自体は任意だが、
置くときは date / time / source / url の4項目すべてを書く。時刻が分からなければ time は「不明」）。
地点パネルに出典リンク付きで表示し、上の表のとおり期待度の底上げとピンの色
（3日以内=🟡、シーズン内=⚪、当日=🟢）にも反映する。
**外部記録だけでは♪2が上限**。♪3以上はアプリへのリアルタイム投稿でしか付かない。
日付が `YYYY-MM-XX`（日にち不明）の記録はシーズン内扱いのみ。シーズン外・未来の日付は無視する。

## データモデル

### places（DBではなく src/data/places.json）

`id`（英小文字とハイフン） / `name` / `pref` / `city` / `lat` / `lng`

運営がキュレーションする。ユーザーは新規作成できない（既存スポットから選ぶ）。
選定基準は AGENTS.md の「スポットデータの決まり」を参照。

### reports（Supabase、唯一のテーブル）

`id` / `place_id` / `heard`(bool) / `latitude` / `longitude` / `accuracy` / `comment`(≤200字) / `created_at`

セキュリティ: 匿名ユーザーは select と insert のみ。update / delete は誰にもさせない。
`created_at` は「さっき聞いた分を記録」でアプリが指定する。未来の時刻と、
2日より前へのさかのぼりは insert ポリシーで弾く。
DDL: [supabase/schema.sql](../supabase/schema.sql)

### お試しモード

Supabaseの環境変数が無いときは自動で切り替わる。サンプル投稿を表示し、
投稿は端末のlocalStorageにのみ保存。画面上部にその旨のバナーを出す。

## 仕様書v0.1からの変更

| v0.1の項目 | 実装 | 理由 |
|---|---|---|
| 録音・写真の添付（任意） | 見送り | ファイル保存と不適切投稿対策が重く、公開が遅れる。ロードマップ入り |
| 地名検索 | 一部実装 | 登録スポット名・市区町村での検索を2026-08-08に追加。未登録の住所・駅名から探す外部ジオコーディングは引き続き見送り |
| 信頼度表示（高/中/参考） | 簡略化 | 「今日◯件・昨日◯件・シーズン計◯件」の実数表示に変更 |
| ホーム/地図/地点ページの分離 | 1画面に統合 | 画面遷移を無くし、5秒投稿を確実にするため |
| 初期データ100〜300箇所 | 156箇所 | 質を優先し実地で追加していく |
| （なし） | 聞きどきを朝夕2回に | ヒグラシは夜明け前後にもよく鳴く。夕方だけ案内すると朝に行ける人を取りこぼすため |
| （なし） | X共有をMVPに繰り上げ | 拡散手段が無いと利用者が集まらないため |
| 鳴き方の記録（任意） | 見送り | 「今日聞けるか」への寄与が小さい |

# 実装済み仕様（MVP as-built）

元になった「MVP仕様書 v0.1」を、実際に作った姿に合わせて更新したもの。
v0.1からの変更点は最後の「仕様書v0.1からの変更」にまとめてある。

> ここに書いてあるのは **いま動いている姿**。地図画面はこのあと
> [design-handoff/](design-handoff/) の案Bに作り替える予定で、そちらはまだ実装されていない。
> 期待度の計算式とデータモデルは再設計後も変わらない。

## 画面構成

1画面完結。地図＋下のパネルで全機能をまかなう（画面遷移なし）。

### ヘッダー

- タイトル「ひぐらしのなくところに」
- キャッチコピー「今日、カナカナが聞こえる場所。」
- 今日の日の入り時刻（概算±15分）と「前後30分が聞きどき」の案内

### 地図

- MapLibre GL + 国土地理院タイル
- スポットをピン（丸）で色分け表示:
  - 🟢 今日「聞こえた」報告あり
  - 🟡 3日以内
  - ⚪ 今シーズン（6/1以降）
  - ⚫ 今シーズンの記録なし
- ピンはズームに応じて大きさが変わる。タップ判定は周囲10pxまで拡大
- 現在地ボタン（MapLibre標準のGeolocateControl）
- 凡例は左上に1行の帯で表示

### 下のパネル（未選択時）

- 地点名検索（2026-08-08追加のつなぎ実装。UI再設計の案B検索に将来置き換え）:
  - 登録スポットの名前・市区町村・都県名で絞り込み（全角半角・大小文字の違いは吸収）
  - 該当0件のときは「見つかりませんでした」の案内と「登録のない場所には投稿できない」旨を表示
  - 検索中はパネルの高さを固定し、結果件数の増減で地図が揺れないようにしている
- 現在地があれば「近くのおすすめ」、なければ「いま期待できる場所」を上位5件
- 各行: 名前 / 市区町村 / 距離 / 期待度★ / 最終確認時刻

### 下のパネル（スポット選択時 = 地点ページ相当）

- 地点名・所在地・鮮度ラベル
- 今日の期待度（★0〜5）
- 最終確認時刻
- 今日◯件確認・昨日◯件・今シーズン計◯件
- 大きな2ボタン: 「🌲 カナカナ聞こえた！」「🌙 今日は静かだった」
- 任意の一言コメント（200字まで、折りたたみ）
- 今日の報告一覧（最新8件）
- X共有リンク

### 投稿フロー

1. スポットを選ぶ（地図のピン or おすすめリスト）
2. ボタンを押す（この時点でGPSを取得。取れなくても投稿は通る）
3. 完了画面「カナカナ情報を受け取りました。今日ヒグラシを探している誰かの助けになります。」
4. 「聞こえた」のときは「𝕏 でシェアする」ボタンを表示

制約: 同じスポットへの連続投稿は2分あける（端末内チェック）。

### X共有

- 共有URLは `/?place=地点ID` 形式。開いた人はその地点が選択された状態で着地する
- 文言（聞こえた直後）: 「◯◯でヒグラシの声を確認しました🌲 #ひぐらしのなくところに」

## 期待度の計算（ルールベース、AI不使用）

| 条件 | 点 |
|---|---|
| 30分以内に「聞こえた」 | +30 |
| 3時間以内に「聞こえた」 | +10 |
| 24時間以内に「聞こえた」 | +5 |
| 3時間以内に「聞こえた」2件以上（複数人確認） | +20 |
| 直近の「聞こえた」がGPS高精度（50m以内、3時間以内） | +10 |
| 3時間以内の「静かだった」1件につき | -5（最大-15） |

★変換: 55点以上=5 / 35以上=4 / 20以上=3 / 10以上=2 / 1以上=1 / 0=0
実装: [src/lib/score.ts](../src/lib/score.ts)

## データモデル

### places（DBではなく src/data/places.json）

`id`（英小文字とハイフン） / `name` / `pref` / `city` / `lat` / `lng`

運営がキュレーションする。ユーザーは新規作成できない（既存スポットから選ぶ）。
選定基準は AGENTS.md の「スポットデータの決まり」を参照。

### reports（Supabase、唯一のテーブル）

`id` / `place_id` / `heard`(bool) / `latitude` / `longitude` / `accuracy` / `comment`(≤200字) / `created_at`

セキュリティ: 匿名ユーザーは select と insert のみ。update / delete は誰にもさせない。
DDL: [supabase/schema.sql](../supabase/schema.sql)

### お試しモード

Supabaseの環境変数が無いときは自動で切り替わる。サンプル投稿を表示し、
投稿は端末のlocalStorageにのみ保存。画面上部にその旨のバナーを出す。

## 仕様書v0.1からの変更

| v0.1の項目 | 実装 | 理由 |
|---|---|---|
| 録音・写真の添付（任意） | 見送り | ファイル保存と不適切投稿対策が重く、公開が遅れる。ロードマップ入り |
| 地名検索 | 一部実装 | 登録スポット名・市区町村での検索を2026-08-08に追加。未登録の住所・駅名から探す外部ジオコーディングは引き続き見送り |
| 信頼度表示（高/中/参考） | 簡略化 | 「今日◯件・昨日◯件・シーズン計◯件」の実数表示に変更 |
| ホーム/地図/地点ページの分離 | 1画面に統合 | 画面遷移を無くし、5秒投稿を確実にするため |
| 初期データ100〜300箇所 | 155箇所 | 埼玉69・東京74・神奈川6・千葉6。質を優先し実地で追加していく |
| （なし） | 日の入り時刻表示を追加 | 「何時に行けばいいか」は聞ける確率に直結するため |
| （なし） | X共有をMVPに繰り上げ | 拡散手段が無いと利用者が集まらないため |
| 鳴き方の記録（任意） | 見送り | 「今日聞けるか」への寄与が小さい |

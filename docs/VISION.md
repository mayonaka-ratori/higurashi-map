# ひぐらしのなくところに — 理念

> **今日、カナカナが聞こえる場所。**

## プロダクト概要

「ひぐらしのなくところに」は、ヒグラシを聞きたい人のためのリアルタイム共有マップ。

このサービスはSNSではない。生物調査アプリでもない。研究データベースでもない。

目的はただ一つ。

**今日ヒグラシを聞きたい人が、聞ける場所へ行けること。**

## 解決したい課題

ヒグラシは好きでも、「今日はどこで鳴いているのか」という情報は、存在していても散在している。
X、ブログ、口コミなどを探し回るしかなく、リアルタイムに探すことが難しい。

本サービスは、その情報を匿名で集約し、「今日、今、どこへ行けば聞けるか」を誰でも分かるようにする。

## ターゲット

- ヒグラシが好きな人
- 夏の風景や音を楽しみたい人
- 写真・録音・自然観察が好きな人
- 子どもとヒグラシを聞きに行きたい家族

## プロダクトの価値

ユーザーが知りたいのは、**「今日行けば聞ける？」** この一点。
すべての機能は、この問いに答えるためだけに存在する。

## プロジェクト憲章

- ヒグラシを聞きたい人のためだけに作る
- 投稿は5秒以内で終える
- 登録を強制しない。匿名で使える
- SNSにしない。学術データベースにしない
- 情報量より「今日聞けるか」を優先する
- 世界観は少しだけ添える。実用性を最優先する
- 機能追加時は「ヒグラシを聞ける確率が上がるか？」を必ず判断基準にする

## 絶対に作らないもの

アカウント機能 / プロフィール / フォロー / いいね / DM / コメント欄 /
ランキング / ポイント / バッジ / ゲーミフィケーション

ここでいう「コメント欄」は、人どうしがやりとりする場のこと。
報告に添える一言（200字まで）はこれに当たらない。
「園内のどのあたりで鳴いていたか」を次に行く人へ渡すためのもので、
返信も表示名も付けない。

## 開発方針

まずはMVPを完成させ、小さく公開し、実際のヒグラシ好きに使ってもらいながら改善する。
機能を増やすことよりも、「今日ヒグラシを聞けた」という体験を増やすことを優先する。

## ゴール

毎年夏になると、「今年も鳴き始めたかな。」——そう思った人が自然に開く場所になること。
夏の訪れを知らせる、小さくても長く愛されるサービスを目指す。

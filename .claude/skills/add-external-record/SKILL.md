# 外部記録（externalRecord）の追加手順

運営が公式サイト・ブログ・登山記録（YAMAP/ヤマレコ）・X・YouTubeなどで見つけた
「この場所でヒグラシが鳴いていた」という記録を、src/data/places.json の該当スポットの
`externalRecord` に載せる。地点パネルに出典リンク付きで表示され、期待度とピンの色が変わる。

## 手順

1. **出典を実際に開いて確認する**（WebFetchまたはブラウザ）。確認すること:
   - ヒグラシ（カナカナ）の記録であること。「セミ」だけでは足りない
   - 場所が places.json のスポットと同じ場所を指していること
   - 日付が特定できること（記事の日付ではなく、聞いた日）
2. **形式**: 4項目すべて必須（検査スクリプトが機械チェックする）:
   ```json
   "externalRecord": { "date": "2026-08-07", "time": "夕方", "source": "媒体名「記事タイトル」", "url": "https://..." }
   ```
   - `date`: `YYYY-MM-DD`。日にちが分からなければ `YYYY-MM-XX`（シーズン内扱いのみになる）
   - `time`: 「夕方」「朝」「日中」「夜明け前」など短い日本語。分からなければ「不明」
   - `source`: 既存の記載に倣う。例「YAMAP 活動日記「高尾山稲荷山コース」」「個人ブログ note「◯◯」」
3. **載せない条件**: シーズン外（6/1より前）の日付・未来の日付はアプリ側で無視されるので載せない。
   去年以前の記録も載せない（「今日聞けるか」に寄与しないため）。
4. **1スポット1件**。すでに `externalRecord` がある場合は、より新しい・確かな記録なら置き換える。
   古い方が確かなら残す。
5. 編集するとフックが自動で `scripts/validate-places.mjs` を実行する。エラーが出たら直す。
6. **報告**: スポット名 / 記録の日付 / 出典 / 期待度への効果を一覧で報告する。
   効果の目安: 3日以内の記録=ピン🟡＋10点、シーズン内=ピン⚪＋5点。
   外部記録だけでは♪2が上限（♪3以上はアプリへのリアルタイム投稿のみ）。

## 注意

- 出典URLは恒久的に残りそうなものを選ぶ（トップページより記事単体のURL）。
  ただし公式サイトが日記形式でURL固定の場合はそのままでよい（例: 埼玉県自然学習センター）
- 該当スポットが places.json に無い場合は、先に /add-spot でスポット自体を追加するか検討する。
  スポットの選定基準（薄暗い林・斜面林・社叢・丘陵・渓谷）はそこで確認する

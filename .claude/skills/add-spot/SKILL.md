# スポット追加の手順

ユーザーから場所の名前（複数可）を受け取り、src/data/places.json に追加する。

1. **選定基準の確認**: そのスポットがヒグラシの生息環境（薄暗い林・斜面林・社叢・丘陵・渓谷）に
   合うか判断する。明るい平地の芝生公園なら、追加する前にユーザーへ
   「基準に合わない可能性」を伝えて確認を取る。
2. **座標の暫定値を置く**: 自分の知識から緯度経度を概算で出す（小数3桁程度）。
   ここではまだ確定させない。次の手順で必ず実データと突き合わせる。
3. **追記**: places.json の該当都県のまとまりに追記する。形式:
   `{ "id": "英小文字とハイフン", "name": "正式名称", "pref": "◯◯県", "city": "◯◯市", "lat": 35.xxx, "lng": 139.xxx }`
4. **座標の検算（必須）**: `node scripts/check-coords.mjs <追加したid...>` を実行し、
   OpenStreetMap の実データと突き合わせる。**知識からの手入力は平均1km、最大3.6kmずれる**
   （2026-08-08に155箇所で検証した実績値）。省略しないこと。
   - 出た候補は必ず目視で確認する。同名の**バス停・駅・ゴルフ場・宿泊施設・案内看板**を
     拾うことがある。地物の種類（`park` `peak` `waterfall` など）を見て、行き先として
     妥当なものだけ採る
   - 渓谷・尾根道など**線状に広がる場所**と、**OSMに未登録の場所**は照合できない。
     その場合は概算のまま残し、手順6の報告で「要実地確認」と明記する
5. **検査**: 編集するとフックが自動で `scripts/validate-places.mjs` を実行する。
   エラーや近接の注意が出たら解消する。
6. **報告**: 追加した各スポットについて「名前 / 市区町村 / 座標の確度（実データ照合済み・要実地確認）」を
   一覧で報告する。検算で採らなかった候補があれば、その理由も添える。
7. **多数（10箇所以上）追加したとき**: spot-reviewer エージェントに追加分のレビューを依頼する。

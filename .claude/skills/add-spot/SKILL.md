# スポット追加の手順

ユーザーから場所の名前（複数可）を受け取り、src/data/places.json に追加する。

1. **選定基準の確認**: そのスポットがヒグラシの生息環境（薄暗い林・斜面林・社叢・丘陵・渓谷）に
   合うか判断する。明るい平地の芝生公園なら、追加する前にユーザーへ
   「基準に合わない可能性」を伝えて確認を取る。
2. **座標の決定**: 自分の知識から緯度経度を概算で出す（小数3桁程度）。
   施設の中心か、緑地の中心付近を指すこと。自信がない場合はWebSearchやWebFetchで確認する。
   それでも不確かなら、その旨をユーザーに伝えたうえで概算値を使う（あとで実地修正する運用）。
3. **追記**: places.json の該当都県のまとまりに追記する。形式:
   `{ "id": "英小文字とハイフン", "name": "正式名称", "pref": "◯◯県", "city": "◯◯市", "lat": 35.xxx, "lng": 139.xxx }`
4. **検査**: 編集するとフックが自動で `scripts/validate-places.mjs` を実行する。
   エラーや近接の注意が出たら解消する。
5. **報告**: 追加した各スポットについて「名前 / 市区町村 / 座標の確度（確実・概算・要実地確認）」を
   一覧で報告する。
6. **多数（10箇所以上）追加したとき**: spot-reviewer エージェントに追加分のレビューを依頼する。
